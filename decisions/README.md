# Architecture Decision Records

This directory records significant design decisions made during development.
Each ADR captures the context, the decision, and its consequences — the *why*, not just the *what*.

## Template

```markdown
# ADR-NNNN: Title

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Deprecated | Superseded by ADR-NNNN
**Deciders:** Brian Chapman, Jeremiah Chapman

## Context

[The situation that motivates this decision. What forces are at play?]

## Decision

[The change that is being proposed or was made.]

## Consequences

[What becomes easier or harder as a result. Trade-offs accepted.]
```
